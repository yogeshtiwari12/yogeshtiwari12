- MERN Stack with Socket.IO for bi-directional communication
- Redux Toolkit for scalable client-side state management
- JWT authentication and room-based messaging architecture
- Real-time typing indicators and online/offline presence tracking

## E-Commerce Platform
A scalable and production-ready e-commerce solution with complete admin and order management capabilities.

- Built with Next.js + TypeScript for end-to-end type safety
- Role-based access control (Admin / User / Delivery Agent)

- Real-time booking updates and customer management
- Built using MERN Stack architecture
